# Place of the Day

ثلاثة أماكن في اليوم (06:10 و12:10 و18:10 UTC)، بجودة عالية، بلا أي صور خرائط من Google.

## التشغيل (مرة واحدة)
1. مستودع **عام** على GitHub، وارفع كل المحتويات (بما فيها مجلد data).
2. في ملف `src/wiki.py` غيّر سطر `UA` ليحمل رابط مستودعك وبريدك (تطلب Wikimedia ذلك).
3. Secrets: `YT_CLIENT_ID` و`YT_CLIENT_SECRET` و`YT_REFRESH_EN` (استخرجه بـ get_token.py).
4. `Actions ← Run workflow` يدوياً أول مرة: تظهر نتيجة فحص المصادر الحية (`--check`) قبل أي نشر.

## ملفات
- `data/places.json`: قائمة الأماكن (عناوين ويكيبيديا + القارة). عدّلها بحرية: كل عنصر لا يمر من فلاتر الجودة والقيم يُتخطى تلقائياً.
- `channels.json`: القناة. للغة جديدة لاحقاً: أضف قوالب الجمل في `src/story.py` وصوتاً في `video.py`.

## فلاتر الجودة والقيم
- ≥ 4 حقائق من Wikidata و≥ 2 صورة بترخيص مقبول (Public domain, CC0, CC BY)، وإلا يُتخطى المكان.
- يُرفض آلياً: أي كيان له دين غير الإسلام (P140)، وأنواع دور العبادة والمقابر والكازينوهات والملاهي.
- لا ترخيص BY-SA أو NC أو ND للصور، ولا نسخ لنصوص ويكيبيديا.
