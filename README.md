# أين في العالم / Where In The World Daily

ثلاثة أماكن يومياً (06:10 و12:10 و18:10 UTC) بالعربية أو الإنجليزية، بلا صور خرائط من Google.

## اللغة
- القناة العربية: `channels.json` فيه `{"id":"ar","lang":"ar"}`، والسر المطلوب `YT_REFRESH_AR`.
- القناة الإنجليزية: `{"id":"en","lang":"en"}`، والسر `YT_REFRESH_EN`.
- يمكن وضع القناتين معاً في الملف نفسه (يتضاعف زمن التشغيل)، والأفضل مستودع لكل لغة.

## التشغيل
1. مستودع **عام**، وارفع كل المحتويات (مع data و.github).
2. الأسرار: `YT_CLIENT_ID` و`YT_CLIENT_SECRET` و`YT_REFRESH_AR` (أو EN).
3. Actions ← Run workflow يدوياً أول مرة: خطوة `--check` تفحص المصادر الحية قبل النشر.

## فلاتر
- ≥ 4 حقائق و≥ 2 صورة بترخيص Public domain/CC0/CC BY، وإلا يُتخطى المكان.
- يُرفض آلياً: أي كيان له دين غير الإسلام، ودور العبادة والمقابر والكازينوهات والملاهي.

## منع التكرار (مهم)
- يُحجز المكان ويُدفع إلى GitHub **قبل** بناء الفيديو ورفعه؛ وإن تعذّر الحفظ لا ينشر شيئاً (يظهر فشل أحمر).
- كل تشغيل يبدأ من آخر حالة في الخادم ويدمجها، فلا تشغيل قديم ولا متزامن ينشر مكاناً منشوراً.
- حماية ثانية اختيارية: ضع `"channel_id": "UC..."` في `channels.json` فيقرأ آخر 15 عنواناً من خلاصة القناة العامة ويتخطى أي مكان ظهر فيها.
- المكان يُعرَّف بمعرّف Wikidata (QID) وليس بالاسم فقط.
